AN INTERACTIVE TRIBUTE

KINGDOM HEARTS — MEMORY —

記憶を辿る、光と闇の旅へ

記憶を辿りはじめる アルバムを見る
SCROLL
Concept

読むサイトではなく、
辿るサイトへ。

このサイトは、キングダムハーツシリーズの世界観から着想を得たオリジナルの体験型Webサイトです。 情報をただ並べるのではなく、訪れた人が自分の手で光を見つけ、記憶を集めながら シリーズの歩みを辿っていく——そんな体験そのものを設計しました。

HEART

こころ

シリーズが一貫して描いてきたのは「心のつながり」でした。 そのテーマを、画面に触れたときの反応や光の揺らぎとして表現しています。

MEMORY

記憶

サイトの各所には「記憶の欠片」が隠されています。 集めた記録はブラウザに保存され、次に訪れたときも引き継がれます。

LIGHT & DARK

光と闇

深い闇を背景に、青白い光だけを頼りに進む構成です。 余白と暗さを活かすことで、ひとつひとつの光が意味を持ちます。

記憶は 薄れても、
つながりは 消えない。

Explore

六つの扉

それぞれの扉が、異なる記憶へと通じています。順に辿っても、気になるところから開いても構いません。

01

MEMORY ALBUM

シリーズ各作品を年代順に辿る記録の間。 作品とキャラクターの記憶がここに収められています。

ENTER 02

TIMELINE

全作品を「発売日順」と「物語内の時系列順」の 2つの表で整理。ずれた時間軸を見渡せます。

ENTER 03

MEMORY THEMES

シリーズを彩ってきた代表曲の紹介。 曲名・作曲・流れる場面を辿り、各配信サービスへ。

ENTER 04

MEMORY OF SUMMER

『KINGDOM HEARTS II FINAL MIX』特集。 ロクサスの七日間から、作品の魅力を辿ります。

ENTER 05

MEMORY CROSSOVER

ファイナルファンタジー、すばらしきこのせかい、 ディズニー——KHと縁のある作品の一覧。

ENTER LOCKED

SECRET MEMORY

記憶の欠片をあと8個集めると開かれる、 隠された記録。まだ語られていない言葉が眠っています。

ENTER
Collect

記憶の欠片を集める

サイトのあちこちに、青白く光る小さな欠片が隠れています。 見つけてクリックすると集めることができ、 8個以上集めると SECRET MEMORY が開かれます。
