# assets — 画像を追加する場所

このフォルダに画像を置き、`js/data.js` の `image` 項目にパスを書くと、
サイト上で自動的に表示されます。何も置かなければ、これまで通り
SVGで描いた紋章や頭文字が表示されるので、**空のままでも問題なく動きます**。

BGM に音源ファイルを使いたい場合は `assets/audio/` フォルダと
`assets/audio/README.md` を参照してください(こちらも任意で、
何も置かなければ合成 BGM が鳴ります)。

## 置くだけツール(style_images.py)を使う(いちばん楽)

画像を `assets/_inbox/` に放り込んで実行するだけで、**枠の比率に切り抜き →
サイトの配色に色を寄せる → 正しい名前で保存 → data.js に配線** まで一括で行います。

```
python assets/style_images.py          # 確認のみ
python assets/style_images.py --apply  # 実行
```

詳しくは `assets/_inbox/README.md`。色を変えたくない場合は `--no-grade` を付けます。
下の sync_images.py は「配線だけ」を行う下位ツールで、style_images.py が内部で呼びます。

## 一括反映ツール(sync_images.py)を使う(配線だけ)

画像を1件ずつ手作業で `data.js` に書き込むのは手間がかかるため、
決まった名前で画像を置くだけで自動反映してくれるスクリプトを用意しています。
Pythonが使える環境で、プロジェクトフォルダから次のように実行してください。

```
# 1. まず、期待されるファイル名の一覧を確認する(画像はまだ無くてOK)
python assets/sync_images.py --list

# 2. 表示された名前で、画像を assets/works・characters・worlds に置く

# 3. 反映される内容を確認する(この時点では data.js はまだ書き換わらない)
python assets/sync_images.py

# 4. 内容を確認して問題なければ、実際に data.js を書き換える
python assets/sync_images.py --apply
```

`--apply` の前には自動で `js/data.js.bak` にバックアップが作られるので、
反映後に元に戻したくなった場合は `.bak` ファイルを `data.js` に戻してください。
このツールは**ファイル名からdata.jsへの「配線」を自動化するだけ**で、画像そのものを
どこかから取得することはしません(理由は次の項目を参照)。

## パッケージ画像を追加する(手動で1件ずつ行う場合)

1. 画像ファイルを `assets/works/` に置く(例:`kh1.jpg`)
2. `js/data.js` の該当する作品を探し、`image: null` を書き換える

```js
{
  id: "kh1",
  year: "2002",
  title: "KINGDOM HEARTS",
  ...
  image: "assets/works/kh1.jpg",   // ← ここを書き換える
  ...
}
```

カードのビジュアル枠は横長(16:10)です。縦長のパッケージ画像を入れると
上下が切り取られるので、あらかじめトリミングしておくか、
`css/pages.css` の `.work-card__visual { aspect-ratio: 16 / 10; }` を
`3 / 4` などに変えてください。

## ワールド画像を追加する

1. 画像ファイルを `assets/worlds/` に置く(例:`destiny-islands.jpg`)
2. `js/data.js` の `WORLDS` の該当ワールドを探し、`image: null` を書き換える

```js
{
  name: "デスティニーアイランド",
  en: "DESTINY ISLANDS",
  ...
  image: "assets/worlds/destiny-islands.jpg",   // ← ここを書き換える
  ...
}
```

カードのビジュアル枠は横長(4:3)です。ファイル名の拡張子で表示方法が自動的に変わります:

- `.png`(ロゴ的な画像向け):画像は切り抜かれず全体が収まる表示(`object-fit: contain`)。
  余白ごと収まるので、特にトリミングしなくても問題ありません
- `.jpg`(画面いっぱいの写真・スクリーンショット向け):枠に敷き詰める表示
  (`object-fit: cover`。上下左右は切り抜かれ、下端は本文パネルの色に馴染むよう
  グラデーションがかかります)

## キャラクター画像を追加する

1. 画像ファイルを `assets/characters/` に置く(例:`sora.png`)
2. `js/data.js` の `CHARACTERS` の該当人物の `image` を書き換える

```js
{
  initial: "S",
  name: "ソラ",
  ...
  image: "assets/characters/sora.png",   // ← ここを書き換える
  ...
}
```

表示枠は正円です。顔が中央にくるようトリミングしておくと綺麗に収まります。
背景が透過しているPNGだと、周囲の光の輪と馴染みます。

## 画像を用意するときの注意

キングダムハーツの公式画像(ロゴ・キャラクターイラスト・パッケージ写真・
スクリーンショット)はスクウェア・エニックスおよびディズニーの著作物です。
**AIやスクリプトによる自動取得(Web上からの一括ダウンロードなど)は行っていません。**
画像は、自分で購入したソフトを自分で撮影した写真や自作イラストなど、
自分自身が合法的に用意できるものだけを置いてください。
授業内での提出にとどめ、Web上に公開する場合は取り扱いに注意してください。

画像を置かない項目は、CSS・SVG・Canvasだけで生成した紋章や頭文字が
そのまま表示されます。これは著作権上の制約からの妥協ではなく、
企画書の「重要な設計原則」(公式サイトの再現ではなくオリジナル企画として表現する)
そのものでもあるので、画像を一切足さずに提出することもできます。
(現在は WORKS・WORLDS・CHARACTERS の多くに、自分で用意した画像が配線済みです。
SECRET・SUMMER・CROSSOVER 各ページの場面ギャラリーについては、それぞれの
フォルダ内 README〔`assets/scenes/`・`assets/roxas/`・`assets/crossover/`〕を参照)

## ファイル形式と容量の目安

- 形式:`.jpg`(写真・パッケージ)/ `.png`(透過が必要なもの)/ `.webp`
- 容量:1枚あたり 300KB 以下を目安にすると表示が軽くなります
- ファイル名:半角英数字とハイフンのみ(日本語やスペースは避ける)
