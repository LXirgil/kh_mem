# assets/audio — BGM 音源を追加する場所

このフォルダに音源ファイルを置き、`js/data.js` の `AUDIO_CONFIG.bgmSrc` に
パスを書くと、サイトの BGM が合成音からその音源に切り替わります。
何も置かなければ、これまで通り `js/audio.js` が Web Audio API で合成した
環境音が BGM として鳴るので、**空のままでも問題なく動きます**。

効果音(ホバー音・クリック音・欠片獲得音など)は常に合成音のままです。
このフォルダの音源は次の2用途で使えます。

- **サイト全体の BGM**(`AUDIO_CONFIG.bgmSrc`)
- **MEMORY THEMES ページの試聴曲**(`THEME_TRACKS` の各曲の `audio`)

## A. サイト全体の BGM にする場合

1. 音源ファイルをこのフォルダに置く(例:`bgm.mp3`)
   - ファイル名は半角英数字とハイフンのみ(日本語・スペースは避ける)
2. `js/data.js` の先頭付近にある `AUDIO_CONFIG` を編集する

```js
const AUDIO_CONFIG = {
  bgmSrc: "assets/audio/bgm.mp3",  // ← null からパスに書き換える
  bgmVolume: 0.28,                 // 0〜1。うるさければ下げる
  bgmLoop: true,                   // ループ再生
  fadeInSeconds: 4,                // 鳴り始めのフェードイン秒数
  fadeOutSeconds: 1.2              // 停止時のフェードアウト秒数
};
```

3. ローカルサーバーを起動して確認する

```
python -m http.server 8000
```

`http://localhost:8000/index.html` を開き、ヘッダーの音声トグルを ON にすると
BGM が鳴ります。`file://` で直接開くと、ブラウザによっては音源を
読み込めないことがあるので、サーバー経由での確認を推奨します。

## B. MEMORY THEMES ページで試聴できるようにする場合

MEMORY THEMES ページ(`music.html`)は、既定では **曲を紹介して各配信サービスへ
案内するだけ** のページです(Spotify・Apple Music・YouTube などの検索リンクが
`js/data.js` の `MUSIC_PLATFORMS` から自動で付きます)。
特定の曲を **サイト内で試聴** させたいときだけ、次の手順で音源を足します。

1. 曲ごとに音源ファイルをこのフォルダに置く(例:`the-other-promise.mp3`)
2. `js/data.js` の `THEME_TRACKS` から該当する曲を探し、`audio` を書き換える

```js
{
  id: "the-other-promise",
  title: "The Other Promise",
  ...
  audio: "assets/audio/the-other-promise.mp3",  // ← null からパスに書き換えると再生ボタンが出る
  query: "The Other Promise Kingdom Hearts 下村陽子",  // 配信サービスの検索語
  links: {                                       // 任意。直リンクを入れたいサービスだけ
    // spotify: "https://open.spotify.com/track/...",
    // apple:   "https://music.apple.com/jp/album/...",
  }
}
```

3. `http://localhost:8000/music.html` を開き、その曲の再生ボタンを押す

`audio` が `null` の曲は再生ボタンが出ず、紹介と配信リンクだけになります。
`links` に URL を書いたサービスは、検索リンクの代わりにその直リンクになります。

## 動作の仕様

### BGM(A の場合)

- 音声トグルが ON のときだけ再生され、OFF でフェードアウトして停止します。
- ページを移動するとその都度読み込み直します(ページ間で連続再生はしません)。
- 音源の読み込み・再生に失敗した場合は、コンソールに警告を出したうえで
  自動的に合成 BGM にフォールバックします(サイトは止まりません)。

### THEMES ページの試聴(B の場合)

- 音声トグルとは独立して動きます(再生ボタンを押すと鳴ります)。
- 同時に鳴るのは1曲だけ。別の曲を再生すると前の曲は止まります。
- 試聴中は、BGM が鳴っていれば自動的に音量を絞ります(`duckBgm`)。
- 再生に失敗した曲はトーストで知らせ、そのカードを停止状態に戻します。

### 共通

- 対応形式はブラウザ依存です。`.mp3` が最も無難で、`.ogg` / `.m4a` も概ね動きます。
- 容量の目安:1曲あたり数MB程度に収めると読み込みが軽くなります
  (長い曲は必要な部分だけ切り出す/ビットレートを下げる)。

## 音源の著作権について(重要)

キングダムハーツの楽曲(「The Other Promise」「Dearly Beloved」「Sanctuary」など、
下村陽子氏の作曲によるゲーム内楽曲・主題歌・サウンドトラック音源)は、
**スクウェア・エニックスおよび権利者の著作物です**。市販のサントラ音源や
ゲームから抽出した音源をこのフォルダに置いてサイトで配信すると、
学校の課題であっても著作権侵害になり得ます。

このフォルダに置いてよいのは、次のように**自分が合法的に用意できる音源**だけです。

- 自分で作曲・演奏・打ち込みしたオリジナル曲、または自作のアレンジ
- CC0 / ロイヤリティフリーなど、利用条件を満たしたライセンス音源
- 権利者から明示的に利用許諾を得た音源

いずれの場合も、**授業内での提出にとどめ**、Web 上に公開する際は
ライセンス表記や利用範囲に十分注意してください。
このプロジェクトでは、音源ファイルの自動取得(Web からのダウンロード等)は行いません。
